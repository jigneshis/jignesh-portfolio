## 4. Routing Architecture

### 4.1 Route Map

| Route | Type | Component | Data Source |
|-------|------|-----------|-------------|
| `/` | Static (SSG) | `app/page.tsx` | All data files |
| `/projects` | Static (SSG) | `app/projects/page.tsx` | `projects.ts` |
| `/projects/[slug]` | Static (SSG) | `app/projects/[slug]/page.tsx` | `projects.ts` (future) |

### 4.2 Rendering Strategy
- **All pages are statically generated (SSG)** at build time
- No server-side rendering needed — all content is static
- `generateStaticParams()` for dynamic project routes
- ISR (Incremental Static Regeneration) not needed — redeploy on content change

```css
@import "tailwindcss";

@theme {
  /* Colors */
  --color-background: #ffffff;
  --color-foreground: #000000;
  --color-muted: #666666;
  --color-muted-foreground: #999999;

  --color-accent: #22c55e;
  --color-surface-dark: #000000;
  --color-surface-dark-foreground: #ffffff;

  /* Border radius */
  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 16px;
  --radius-xl: 20px;
  --radius-full: 9999px;

  /* Spacing scale extends defaults */
  --spacing-section: 10rem;    /* 160px vertical section padding */

```

### 5.2 Dark Mode Strategy
- **Class-based** (`.dark` on `<html>`) — NOT media query based
- Toggle button in navbar
- System preference detected on first visit via `window.matchMedia`
- User preference persisted in `localStorage`
- Smooth transition via `transition-colors duration-300` on body

### 5.3 Responsive Breakpoints
| Name | Width | Usage |
|------|-------|-------|
| `sm` | 640px | Small mobile tweaks |
| `md` | 768px | Tablet — stack columns |
| `lg` | 1024px | Desktop — two-column layouts begin |
| `xl` | 1280px | Wide desktop — max-width container |
| `2xl` | 1536px | Ultra-wide — no layout changes, just breathing room |

## 6. Animation Technical Specs

### 6.1 Library Choices

| Animation | Library | Rationale |
|-----------|---------|-----------|
| Hero parallax cards | Framer Motion (`useScroll` + `useTransform`) | Scroll-linked, needs smooth interpolation |
| Nav morph | Framer Motion (`layout` + `AnimatePresence`) | Layout animation with enter/exit |
| Custom cursor | Framer Motion (`useMotionValue` + `motion.div`) | Smooth mouse-following with spring physics |
| Section reveals | Framer Motion (`whileInView` + `variants`) | Intersection-based with stagger |
| FAQ accordion | Framer Motion (`AnimatePresence` + `layout`) | Height animation |
| Footer word cycler | Framer Motion (`AnimatePresence` + `variants`) | Vertical slide transition |
| Logo marquee | CSS `@keyframes` | Infinite scroll, GPU-accelerated, no JS needed |
| Smooth scroll | Lenis | Native scroll behavior enhancement |

### 6.2 Performance Guidelines
- Use `will-change` sparingly and only on actively animating elements
- Prefer `transform` and `opacity` animations (compositor-only)
- Set `layoutScroll` on scroll containers for Framer Motion
- Disable all animations when `prefers-reduced-motion: reduce` is active
- Lazy-load below-fold sections to reduce initial animation work
- Use `React.memo` on expensive animated components
- Target 60fps — test on 4x CPU throttle in Chrome DevTools

### 6.3 Smooth Scroll Configuration
```typescript
// Lenis configuration
{
  duration: 1.2,        // Scroll duration
  easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)), // Ease-out expo
  orientation: 'vertical',
  smoothWheel: true,
  touchMultiplier: 2,
}
```

## 8. Image Optimization Strategy

| Approach | Implementation |
|----------|---------------|
| Format | WebP/AVIF via Next.js `<Image>` component |
| Lazy Loading | Native `loading="lazy"` for below-fold images |
| Priority Loading | `priority` prop on hero/above-fold images |
| Sizing | `sizes` prop with responsive breakpoints |
| Placeholder | `blur` placeholder with generated blurDataURL |

| Profile Photo | Multiple sizes for nav (40px), hero button (32px), about (400px) |

## 9. Font Strategy

### 9.1 Font Selection
- **Primary:** Inter (or Geist Sans — Vercel's own font, optimized for Next.js)
- **Fallback:** `system-ui, -apple-system, sans-serif`

### 9.2 Loading Strategy
```typescript
// app/layout.tsx
import { Inter } from 'next/font/google';
// OR
import { GeistSans } from 'geist/font/sans';

const inter = Inter({
  subsets: ['latin'],
  display: 'swap',
  variable: '--font-sans',
});
```

- `next/font` handles self-hosting automatically
- `font-display: swap` prevents FOIT
- Variable font reduces total font weight
- Subset to `latin` only

## 10. Accessibility Implementation

| Requirement | Implementation |
|-------------|---------------|
| Semantic HTML | `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `<article>` |
| Landmarks | ARIA landmarks on all major sections with `aria-label` |
| Navigation | `role="navigation"`, skip-to-content link |
| Images | Descriptive `alt` text on all images |
| Links | Descriptive link text (no "click here") |
| Buttons | Proper `<button>` elements, not `<div>` |
| Dark Mode Toggle | `aria-label="Toggle dark mode"`, state announced |
| FAQ Accordion | `<details>/<summary>` or ARIA accordion pattern |
| Focus Management | Visible focus rings on all interactive elements |
| Reduced Motion | Respect `prefers-reduced-motion` — disable animations |
| Color Contrast | Min 4.5:1 for body text, 3:1 for large text |
| Touch Targets | Min 44×44px on mobile |
